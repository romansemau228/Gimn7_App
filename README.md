# Школьный помощник — Telegram Mini App

Веб-приложение для расписания, оценок и домашних заданий XI «Б». Данные хранятся локально в браузере Telegram на устройстве.

## Подключение к Telegram

Разместите `index.html`, `styles.css` и `app.js` на HTTPS-хостинге. Создайте бота через @BotFather, настройте Mini App и укажите адрес размещённой страницы в параметрах приложения. Для кнопки «На экран» можно задать квадратную иконку Mini App в BotFather. SDK Telegram уже подключён в `index.html`.

Расписание, обычные оценки и задания можно добавлять из интерфейса. Четвертные оценки и прогноз годового результата доступны во вкладке «Оценки».
