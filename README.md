# Школьный помощник

Лёгкое Telegram Mini App для расписания, оценок и домашних заданий. Интерфейс адаптирован для телефона; данные хранятся локально в браузере на устройстве. Оценки настроены на шкалу 1–10, средние баллы и предметные средние рассчитываются автоматически. Подсказки появляются для предметов с низким средним и уроков с указанной темой на следующий учебный день.

## Запуск

Откройте `index.html` в браузере для локального просмотра. Чтобы использовать приложение как Telegram Mini App, разместите файлы на публичном HTTPS-хостинге и укажите URL в настройках бота через BotFather. Сервер и синхронизация не нужны для текущего локального варианта.

Заполните расписание на вкладке «Расписание», оценки — на вкладке «Оценки», задания — на вкладке «Задания». Приложение сохраняет введённое в localStorage текущего браузера.
